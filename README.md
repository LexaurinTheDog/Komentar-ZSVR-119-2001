# Komentář k zákonu č. 119/2001 Sb., kterým se stanoví pravidla pro případy souběžně probíhajících výkonů rozhodnutí

Otevřený komentář k zákonu o souběžně probíhajících výkonech rozhodnutí — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; souběh soudních, exekutorských, daňových a správních exekucí na mzdu, účty, movité věci, nemovitosti a podnik.

Konsolidované znění: dokument e-Sbírky `SB-2001-00119_2024-10-01`.
